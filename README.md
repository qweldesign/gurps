# RPG.LOGIC

## 0. 概要

- React を使用した創作 TRPG シミュレーター / 個人の学習用途を兼ねた実験プロジェクト
- DEMO: [https://rpg-logic.dev/]

---

## 1. 開発経緯等

- 筆者はテーブルトークRPG (TRPG) をやったことは無いが, ルールブックを読むのが昔から好きだった
- 例えば, GURPS (※) の戦闘シーンは, 状況を簡単に数値化できない面白さがある
  - 例えば, ファンブルで武器を落としたり, 壊したりする → 格闘戦や落した武器の奪い合いが始まる
  - 魔法の効果がハチャメチャ → 死人を操ったり, 時間を巻き戻したり (ただし, これは筆者独自に考案)
- 魔法に関しては, 「サガ・シリーズ」の影響を多々受けていますが, 二次創作です

## 3. プロジェクト構成

コードは主に **ドメイン層** と **UI層** の2層で構成され, 加えてドメイン層・UI層のどちらにも属さない補助的な独立ディレクトリが2つ存在する.

| ディレクトリ / ファイル | 区分 | 役割 | 主な内容 |
|---|---|---|---|
| `src/domains/` | ドメイン層 | ゲームのルール・データ・ロジック | |
| `src/domains/Character.ts` | ファイル | キャラクター | キャラクターに関するロジック |
| `src/domains/Equipments.ts` | ファイル | 装備 | 武器・防具などの装備ロジック |
| `src/domains/Parameters.ts` | ファイル | パラメータ | ステータス・能力値など |
| `src/domains/SaveData.ts` | ファイル | セーブデータ | ゲームデータの保存・管理 |
| `src/domains/Sample/` | ディレクトリ | サンプル | サンプルキャラクター生成ロジック |
| `src/domains/Combat/` | ディレクトリ | 戦闘 | 戦闘システム全般 |
| `src/domains/Combat/Unit.ts` + `Unit/` | ファイル+ディレクトリ | 戦闘ユニット | 攻撃・防御・HP・状態異常など, ユニットに関するロジック |
| `src/domains/Combat/Action.ts` + `Action/` | ファイル+ディレクトリ | アクション | 戦闘中の行動の種類・可否判定・効果・解決処理 |
| `src/domains/Combat/AI/` | ディレクトリ | AI | 敵・味方の自動行動判断 (`base/` = 行動タイプ別の基本ハンドラ, `handlers/` = それらを束ねる上位ハンドラ, の2階層構造) |
| `src/domains/Combat/Enemy.ts` + `Enemy/` | ファイル+ディレクトリ | 敵 | 敵キャラクター定義 (ゴブリン・スライム・アンデッドなど) |
| `src/domains/Combat/Spells.ts` | ファイル | 呪文 | 魔法・スペル関連 |
| `src/domains/Combat/{Dice,Difficulty,Formation,Log,Player,State}.ts` | ファイル | 戦闘共通ロジック | ダイスロール, 難度, 部隊編成, ログ, プレイヤー, 戦闘状態 |
| `src/docs/` | 独立ディレクトリ | ドキュメント機能 | ルール文書のMarkdownレンダリング・章立て管理 |
| `src/devProgress/` | 独立ディレクトリ | 開発進捗 | 法術などの開発進捗一覧 (開発用ビュー向け) |
| `src/parts/` | UI層 | Reactによる画面コンポーネント | |
| `src/parts/Setup/` | ディレクトリ | セットアップ画面 | ゲーム開始前の設定 (編成・難度選択・確認・編集) |
| `src/parts/Combat/` | ディレクトリ | 戦闘画面 | 戦闘UI (行動・部隊編成・状況表示・タイムライン) |
| `src/parts/Docs.tsx` | ファイル | ドキュメント画面 | `src/docs/` のデータを表示するUI |
| `src/parts/{Entrance,Sample,DevProgress}.tsx` | ファイル | その他画面 | 入口画面, サンプルキャラクター一覧, 開発進捗ビュー |
| `src/parts/common/` | ディレクトリ | 共通UI部品 | リスト・詳細・モーダルなどの共通コンポーネント |

## 4. ディレクトリ構成

```text
src/
├── App.tsx / router.tsx / index.tsx      # エントリーポイント
│
├── domains/                 # ドメイン層：ゲームのルール・ロジック
│   ├── Character.ts
│   ├── Equipments.ts
│   ├── Parameters.ts
│   ├── SaveData.ts
│   ├── Sample/
│   │   └── Character.ts
│   └── Combat/
│       ├── Action.ts
│       ├── Action/         # types / availability / effects / resolver
│       ├── AI/
│       │   ├── base/       # 行動タイプ別の基本ハンドラ (archer, warrior, 各属性spell 等)
│       │   └── handlers/   # 基本ハンドラを束ねる上位ハンドラ
│       ├── Enemy.ts
│       ├── Enemy/          # Base / Goblin / Slime / Undead
│       ├── Unit.ts
│       ├── Unit/           # Attack / Defense / Health / StatusBuff / StatusEffects
│       ├── Spells.ts
│       ├── Dice.ts / Difficulty.ts / Formation.ts / Log.tsx / Player.ts / State.ts
│
├── docs/                    # ドキュメント機能 (domains/partsどちらにも属さない)
│   ├── chapters.ts
│   ├── docsLoader.ts
│   └── markdown.ts
│
├── devProgress/             # 開発進捗ビュー用データ
│   └── spells.ts
│
└── parts/                   # UI層：Reactによる画面・コンポーネント
    ├── Setup.tsx / Setup/           # セットアップ画面 (編成・難度・確認・編集)
    ├── Combat.tsx / Combat/         # 戦闘画面
    ├── Docs.tsx                     # ドキュメント画面
    ├── Entrance.tsx / Sample.tsx / DevProgress.tsx
    └── common/                      # List / Detail / Modal
```
